# EmpireAI Media Learning Worker

PILLOW-MLW-001 / Q4-16 provides the Media Learning Worker.

The Media Learning Worker learns reusable content patterns from verified Media Analytics Worker reports. It produces machine-readable learning reports covering successful and unsuccessful patterns, topic/hook/thumbnail/retention/publishing insights, recommended improvements, and structural playbook recommendation updates — as structural signals only. It does **not** rewrite existing content, modify published videos, change editorial policy directly, or overwrite historical learning records.

## Authority

The Media Learning Worker:

- operates as an isolated AI Worker (analyst) within the Media Factory
- receives media analytics reports from the Media Analytics Worker
- identifies successful and unsuccessful content patterns
- analyses topic, hook, thumbnail, pacing/retention, and publishing timing performance
- generates reusable learning insights for next-content guidance
- updates media playbook recommendations structurally (never overwrites history)
- learns only from verified analytics
- distinguishes measured outcomes from assumptions
- preserves complete learning traceability and historical learning records
- produces machine-readable Media Learning Reports
- submits reports through the Executive Reporting Runtime
- operates autonomously under Pillow governance

## Boundaries

The Media Learning Worker never:

- rewrites existing content
- modifies published videos
- changes editorial policy directly
- overwrites historical learning
- overrides Pillow
- overrides Grand King
- implements Q4-17 or later

## Mandatory rules

- Learn only from verified analytics
- Preserve complete traceability
- Preserve historical learning records
- Distinguish measured outcomes from assumptions
- Preserve audit history
- Submit reports through the Executive Reporting Runtime
- Never overwrite historical learning
- Never rewrite existing content or modify published videos
- Recommendations only — no content mutation
