# Evidence transport scope

This batch transports a selected evidence set. Historical seals and reports are retained without rewriting their original source attribution. Absolute-path references and historical seals may cover additional locally retained files not included in this publication. Only TRANSPORT-MANIFEST.json defines files actually transported in this batch; it does not assert omitted archives were published.

The original A17 43-file seal was independently verified locally. Selected native API/projection/readback and field evidence is transported, alongside the successor complete-contract acceptance. No actual invoices, private financial exports, credential/session logs or synthetic SQLite snapshots are included. Browser examinations use labelled synthetic accounts and responses.

Source bundles are incremental frontend transport only and are pinned by exact blob, commit and tree in the source CI workflow. No frontend deployment branch moves. Full local archival checkpoint bundles remain local. The combined source awaits bounded publication authority and exact-source hosted CI.
