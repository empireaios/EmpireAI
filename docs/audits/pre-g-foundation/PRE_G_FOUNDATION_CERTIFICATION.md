## Exclusions applied (`.gitignore`)

The following categories are excluded from Git and were inspected before staging:

| Category | Examples / patterns | Reason |
|----------|---------------------|--------|
| Secrets | `.env`, `.env.*` (except `.env.example`) | Live credentials |
| Dependencies | `node_modules/` | Reproducible via lockfiles |
| Build output | `dist/`, `build/`, `.next/`, `out/`, `*.tsbuildinfo` | Regenerated by build |
| Local DB / data | `/data/`, `*.db`, `*.sqlite*` | Machine-local persistence |
| Runtime state | `.empire/`, `.pillow-*/` | Pillow/Empire session state |
| Governance bundle | `.pillow-governance-bundle/`, `backend/.pillow-governance-bundle/` | Prebuild artifact |
| IDE / machine | `.cursor/`, `.vscode/`, `.idea/`, `Thumbs.db` | Machine-specific |
| Logs / temp | `*.log`, `tap-out.txt`, `validation-output.log`, etc. | Ephemeral output |

**On-disk secrets not committed:** `backend/.env`, `frontend/.env` (present locally, ignored).
