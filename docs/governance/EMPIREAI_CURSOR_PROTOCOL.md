## 1. Purpose

P4-04 establishes the **permanent Cursor Protocol** — the constitutional engineering protocol governing every Builder mission generated by Pillow or the Chief Architect.

The protocol standardizes mission generation, execution, reporting, validation, and completion. **Every Builder mission follows one protocol.**

| Cursor Protocol IS | Cursor Protocol IS NOT |
|--------------------|------------------------|
| Constitutional execution lifecycle + mandatory sections | A replacement for Cursor Output Standard format |
| Builder refusal gate when pre-mission checks fail | A competing mission template |
| Single protocol for all missions | Per-mission ad hoc formats |

---

## 2. Mandatory mission sections

Every mission **shall** contain:

| Section | Purpose |
|---------|---------|
| Mission Purpose | Why this mission exists now |
| **WHY** | Vision alignment |
| **WHAT** | Scope boundary |
| **HOW** | Architecture + engineering approach |
| **PROOF** | Acceptance + evidence |
| Roadmap Item | Constitutional programme slot |
| Dependencies | Blockers and prerequisites |
| Context Synchronization | Operational state loaded (P4-03) |
| Architecture Review | Normative architecture alignment |
| Repository Review | Structure + standards compliance |
| Risk Review | Drift and production impact |
| Estimated Completion Time | Planning anchor |
| King Action Required | Irreversible / blocked missions |
| Implementation | Section 2 engineering body |
| Validation | Tests + typecheck + acceptance |
| Repository Acceptance | Journey · audit · drift rules |
| Production Acceptance | Production Truth when scoped |
| Grand King Acceptance | Executive sign-off |
| Lessons Learned | Closeout accumulation |
| Next Roadmap Item | Programme continuity |

**Runtime validation:** `MANDATORY_PROTOCOL_SECTIONS` · `validateProtocolDocument()`

## 3. Mission states (P4-04)

```
Queued → Preparing → Synchronizing → Reviewing → Planning → Implementing
  → Testing → Validating → Production Verification → Awaiting Grand King
  → Completed

Blocked · Recovering · Cancelled (terminal / exceptional)
```

Legacy PILLOW-007 states remain supported with mapping to P4-04 lifecycle.
