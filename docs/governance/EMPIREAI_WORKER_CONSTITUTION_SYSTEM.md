# EmpireAI Worker Constitution System

PILLOW-WCT-001 / Q1-01 provides the Worker Constitution.

The Worker Constitution is the foundational governance framework for every AI Worker in EmpireAI. Every present and future AI Worker must inherit this constitution. No worker may exist outside it.

The Worker Constitution defines what a worker is, what a worker may do, what a worker may not do, how a worker behaves, communicates, reports, remains accountable, and how Pillow governs every worker.

> Note: Doctrine ID is **PILLOW-WCT-001**. There is one authoritative Worker Constitution. Every future AI Worker, regardless of department or factory, must inherit this constitution.

## Boundaries

The Worker Constitution:

- **does** define workforce behaviour, define workforce governance, standardize every worker, and provide one constitutional foundation
- does **not** execute worker tasks
- does **not** replace Worker Quality Standard
- does **not** replace Governance
- does **not** override Pillow
- does **not** override Grand King

## Worker Constitution definition

Each definition includes: Constitution Version, Worker Identity, Worker Purpose, Worker Responsibilities, Worker Authority, Worker Restrictions, Worker Obligations, Communication Standards, Reporting Standards, Quality Standards, Governance Standards, Escalation Standards, Audit Standards, Traceability Standards, and Metadata version (`WCT-001-v1`).

## Mandatory constitutional rules

Default: governed by Pillow, follow executive instructions, never bypass Pillow, never execute outside assigned authority, report all work, preserve audit history, preserve traceability, follow Worker Quality Standard, follow Worker Self-Critique Protocol, participate in Peer Review when required, use approved tools only, escalate beyond authority, remain certifiable at all times.

Additional constitutional rules can be registered through configuration without redesigning the framework.

## Safety

Credentials and authentication tokens are never exposed. Constitutional operations preserve auditability and traceability. Sensitive values are masked in logs. Constitution records never claim that the framework executed worker tasks, replaced Worker Quality Standard, replaced Governance, overrode Pillow, or overrode Grand King.
