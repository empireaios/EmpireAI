## 1. Purpose

Extend the existing Platform architecture so Pillow and the Grand King can understand, navigate, analyse and safely evolve the repository — without repository guessing during Cursor missions.

This extends PILLOW-RI-001 / PILLOW-003 — it does not create a parallel subsystem.

---

## 2. Repository discovery

**Runtime:** `discoverRepositoryInventory()`

Discovers folders · packages · services · APIs · UI · business engines · Pillow modules · infrastructure · tests · documentation.

---

## 3. Architecture intelligence

**Runtime:** `buildComponentIntelligence()` · `buildFolderIntelligence()` · `buildFileIntelligence()`

For every major component: purpose · owner · responsibilities · interfaces · dependencies · dependents · entry points · Pillow relationship · criticality.

---

## 4. Dependency intelligence

**Runtime:** `buildDependencyGraphIntelligence()`

Incoming · outgoing · circular dependencies · unused components · duplicated responsibilities · architectural hotspots.

## 5. Execution flow intelligence

**Runtime:** `getAllExecutionFlows()` — includes authentication · commerce · marketing · executive approval · mission generation · artifact generation · executive home rendering.

## 6. Impact analysis

**Runtime:** `analyzeRepositoryImpact()` — before missions, determines affected folders · files · components · dependency impact · required tests · architectural risks.
