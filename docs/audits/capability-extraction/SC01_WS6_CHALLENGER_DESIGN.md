# SC-01 WS6 — Independent Integration Challenger Design (HELD)

`HELD_FROM_IMPLEMENTATION: true`

## Role

WS6 is an **independent integration challenger** for SC-01 Shadow CEO **path integration** (ordinary Pillow chat, founder cockpit, BFF/Brain, operating-loop durability). It does **not** implement chat admission, pillow-host wiring, or shadow-ceo execution writers. Episodes stay sealed until an integration candidate claims readiness; implementers must not tune to memorized IDs.

## What this pack tests

Machine-verifiable **path + operating-chain** behavior — not prose quality:

## Judgment rules

- Prefer store/API projections over chat wording.
- Brain control-plane truth outranks stale Vercel/UI.
- SYNTHETIC mode must not open live commerce.
- Ordinary non-operating chat must not latch operating mode.
- Parallel-agent agreement is not certification.
