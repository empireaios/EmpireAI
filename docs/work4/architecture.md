## Contracts

Four Eyes, one Pillow. Configuration, credential presence, authentication and named endpoint reads have separate states. Adapters expose fixed read endpoints. CJ freight POST calculates an estimate, never an order. Secrets never enter evidence or source.

Jobs retain requester, objective, ID, capabilities, subject/variant/marketplace, budget, evidence references, outcomes and failures. Maximum 12 outbound requests, four capabilities, 20 outstanding jobs/workspace, 15s/request and 2MiB response. Calls reserve quota before sending, including failures. UTC daily quotas: CJ1,000 points, Amazon100 requests, Keepa100 tokens, public provider100 requests. These are sensing quotas, not AI inference ceilings. No inline retries. Retry-after produces bounded backoff; last good evidence survives failure. Interrupted calls are not blindly replayed.

Cache reuse preserves observation time. Provider success proves only its named scope. Report-list success is not Brand Analytics eligibility. Source text is untrusted evidence and cannot alter provenance, destinations, instructions or authority.

Initial schedules: account daily, catalogs six-hourly, safety daily, internal state every15min. One downstream candidate per catalog and one supplier variant. UTC timestamps; SGT owner display. Collection and stored reads invoke zero LLMs. Pillow receives bounded evidence and can emit a validated job. Results appear in subsequent context; queuing is not judgment/completion. Work3 decisions retain supplied evidence IDs/digests/times; historical claims do not outrank current evidence.
