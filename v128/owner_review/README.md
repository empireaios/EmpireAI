It does not replay `REQUEST_EDIT` or `PROPOSE_RETAINED`, import authentication, run commerce/Pillow, touch production, or infer a personal action from a technical principal. The existing media UI retains original/revised comparison and exact-version approval/rejection. A separate explicit `ACKNOWLEDGE_REVIEW` choice records review without approval or selected assets. The exact native command handler retains its readback in a `finally` block before network completion, including when the caller disconnects. Failed or missing readback prevents a successful export; it is never replaced with a manufactured outcome.

## Hosting and custody boundaries

The root host layer owns immutable provider/source/origin/deadline binding, signed encrypted provisioning, the single public ingress, resource/response limits, and the independent hard timeout. The nonroot `review-supervisor.mjs` starts only fresh Redis, native backend and the newly built Next frontend. The backend stays on loopback 4000, its separately authenticated custody listener on 4001, Redis on 46379 and Next on 43117. The native service never opens a public listener itself.

The owner-review window closes 90 seconds before the immutable service expiry; one owner input also seals immediately. `seal_review.py` verifies the two original events and unrelated state unchanged, correlates any version-3 event with its exact authenticated input and native outcome, and includes actual runtime-manifest, source-manifest and build-provenance bytes. Its fixed-member ZIP is bounded to 64 MiB expanded and 8 MiB compressed and every member is read back by hash.

`review-export.mjs` encrypts this ZIP to the already pinned owner recipient key using the separate Railway-scoped envelope adapter. That adapter preserves the previous cryptographic/runtime/key checks and binds the actual Railway deployment UUID; its decimal identifier is a verified UUID bijection, never an invented GitHub run. The original v126 crypto helper is unchanged.

The fixed encrypted JSON export is available only through the controller-token endpoint and is bounded to 12 MiB. Normal early termination requires acknowledgement of its exact digest. Bounded ciphertext-only numbered log chunks provide an additional recovery path; a partial stream never establishes custody. Early faults allow a bounded sealing interval within the same absolute lease. Hard termination remains unconditional, and missing independent encrypted readback means no acceptance.

Private credentials, plaintext state, authentication stores and raw errors are never logged. No temporary authority extends the original deadline, permits publication, or changes commerce LOCKED, Pillow NOT_BORN or Work 9 INACTIVE.
