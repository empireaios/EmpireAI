# EmpireAI Version 1.0 — Release Notes

**Release:** EmpireAI Version 1.0  
**Date:** 2026-07-03  
**Status:** LOCKED · Production Baseline

---

## Overview

EmpireAI Version 1.0 is the first permanent release of the Grand King AI Operating System. It consolidates G0 through G8 certified programmes, Empire Activation, and Version 1 Lock into a single immutable production baseline.

This release introduces **no new runtime capabilities**. It certifies and locks everything already built.

## Production Configuration

- Private authentication gateway at `/login`
- Root redirect to login or `/cockpit` based on session
- `robots.txt` blocks all crawlers
- `X-Robots-Tag: noindex` on all responses
- Meta robots noindex in application layout
- Production domain: `https://empire-ai.co`

---

## Known Conditions

1. DNS for `empire-ai.co` must be configured to point to Vercel (not GoDaddy parking)
2. In-memory subsystem stores require production persistence configuration at deploy time
3. Voice uses browser Web Speech API

## Upgrade Policy

EmpireAI Version 1.0 is **LOCKED**. Future changes accumulate as unreleased work under **Version 1.x Development** until the Grand King approves Version 1.1, 1.2, 2.0, or later.

Each future version requires: release notes, executive audit, version report, certification summary, and change summary.
