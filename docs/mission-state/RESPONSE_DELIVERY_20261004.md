## Structural contract

Text is not executable authority. No natural-language business vocabulary can call a tool or update governance. Only an entire top-level JSON object can enter the existing calculation protocol. Mixed action envelopes extract exactly one provider-authored `answer`, `content`, or `message`; all action fields are denied and explicitly omitted. Ambiguous or action-only envelopes cannot count as completion. Prose qualifies as reasoning, not as an attestation that an action/retrieval occurred. Heuristic provenance findings are displayed in a clearly server-authored qualification; the model's original text is unchanged, including disagreements and reversals.

The frontend corrections belong to the same bounded defect class. Backend-only deployment is insufficient for complete coverage of quoted infrastructure text. Production frontend PR41 remains unchanged pending explicit authorization of the successor frontend as well as backend.
