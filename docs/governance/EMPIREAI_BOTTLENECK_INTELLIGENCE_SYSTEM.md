## Purpose

The Bottleneck Intelligence module provides continuous bottleneck detection across the EmpireAI scaling pipeline. It monitors operational, infrastructure, supplier, marketing, financial, and workforce bottlenecks; detects throughput constraints; ranks bottlenecks by business impact; and recommends validated resolution paths using structural signals only — never unsupported bottleneck conclusions.
