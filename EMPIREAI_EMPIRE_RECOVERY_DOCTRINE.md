## 1. Doctrine

**No single device shall ever destroy the Empire.**

Loss of laptop, desktop, SSD, Windows installation, Cursor installation, or local development files shall **never** prevent recovery of EmpireAI.

---

## 2. Empire Recovery Assessment

Pillow shall perform an **Empire Recovery Assessment** when Grand King initiates recovery or when Bootstrap detects a recovery session.

### Verification checklist

| Domain | What is verified |
|---|---|
| Repository | Git integrity, remote availability, branch state |
| Journey | `JOURNEY.md` present and parseable |
| Soul | `EMPIREAI_SOUL.md` present |
| Decision Register | `EMPIREAI_DECISIONS.md` present |
| Project Status | `EMPIREAI_STATUS.md` present |
| Deployment | Deployment state / environment configuration |
| Cloud Database | Remote persistence availability (when configured) |
| Local Workstation | Toolchain, Node, dependencies, env files |

---

## 3. Recovery outcome

If **repository integrity exists**, Pillow shall:

1. Produce an **Empire Recovery Report** (structured output).
2. Reconstruct the development environment on a replacement workstation.
3. Guide Grand King through complete recovery step-by-step.

If repository integrity **does not exist**, Pillow shall report blockers and required Grand King actions — never fabricate state.

---

## 4. Pillow deliverable

**Empire Recovery Report** shall include:

* Assessment timestamp  
* Pass/fail per domain  
* Recovery steps ordered  
* Blockers requiring human action  
* Reference to canonical repository owners synchronized
