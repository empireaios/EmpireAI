## Nonduplicative comparison

Keepa supplies longitudinal pricing/rank/offer evidence; SP-API supplies seller-specific permissions, current catalogue/offers, fees and operational data. Rank is a proxy, not verified sales. Jungle Scout supplies estimated sales and search-volume/keyword evidence; those estimates need uncertainty labels. Helium10 overlaps much of Jungle Scout's discovery/keyword work, adding agent-oriented listing/ads tooling; buying both does not repair missing compliance, freight, image licences or assessed product identity.

Keepa supports direct HTTPS JSON and hosted MCP, using the same token entitlement. Official product API supports up to100 ASINs/request. Product-domain table currently lists US/UK/DE/FR/JP/CA/IT/ES/IN/MX/BR; Singapore is not in that table. Jungle Scout public API documents US/UK/DE/IN/CA/FR/IT/ES/MX/JP, restricted further by key. **Verify the intended sales marketplace before any purchase; residence in Singapore does not identify marketplace.**

Jungle Scout API publishes1k/$29,4k/$99,10k/$199 monthly add-ons with$0.05/request overage and page-based charging. Existing Growth/Brand Owner account required; Starter insufficient. Its UI tracker limit is not the API request entitlement. Official REST limit is300 requests/minute and15/second; rate-limited responses require backoff.

Jungle Scout terms§25 permit third-party AI transient inference only if the system retains no supplied data/insights after the session; general IP restrictions also apply. This is material to stored Pillow transcripts/dossiers. Obtain written permission for the exact design or redesign ingestion to permitted retained evidence plus zero-retention inference; do not assume a normal API subscription licenses persistent AI memory. Owner must create their own account under the published account-creation terms.

Helium10's current pricing page establishes up to1,000 included MCP calls, not unlimited; reset period/overage is not stated there. Current terms§5D explicitly allow authenticated approved MCP/programmatic interfaces within scopes and limits. They do not authorize scraping or bulk resale/competing products. Thus authorized agent integration is supported, but full unattended workload and durable retention require contract/entitlement confirmation. Published keyword/product tools exist; API entitlement is not automatically the full UI entitlement.
