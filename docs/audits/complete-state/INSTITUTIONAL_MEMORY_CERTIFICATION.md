## Non-negotiable rule

Institutional memory is **NOT CERTIFIED** merely because:

- memory code exists
- a table / vector store / embeddings exist
- an API exists
- unit tests pass

Complete State Audit requires evidence of the **full lifecycle**:

```
CAPTURE → PERSIST → SURVIVE RESTART → RETRIEVE → ENTER REASONING
→ AFFECT DECISION → RECEIVE OUTCOME → UPDATE / LEARN
→ RETAIN PROVENANCE → CONTINUE ACCUMULATING
```

If any stage is missing: **PERSISTENT CUMULATIVE MEMORY & INSTITUTIONAL LEARNING NOT CERTIFIED**.
