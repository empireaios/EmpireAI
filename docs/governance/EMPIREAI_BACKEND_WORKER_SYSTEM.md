# EmpireAI Backend Worker System

**Doctrine:** PILLOW-BEW-001  
**Mission:** Q6-05  
**Worker:** Backend Worker (`wkr-backend-01`)

## Mandate
The Backend Worker produces structural, secure, maintainable backend module signals from approved requirements and approved architecture. It implements planned REST and GraphQL APIs, modular business services, authentication and authorization, integrations, background jobs, validation, and safe error handling.

## Authority and boundaries
- Pillow remains the executive authority; the Grand King remains supreme authority.
- The worker must never build frontend UI, design new requirements, override approved architecture, override Pillow, override the Grand King, or implement Q6-06 or later.
- Every report preserves approved IDs, traceability references, decisions, validation findings, and audit history.
- Sensitive values are masked in worker logs and structural signals only are retained.

## Required controls
The worker validates input, handles failures safely, produces reusable modular services, runs a self-review before completion, and submits only completed, traceable reports for executive review. It reports Q6-05 progress with an explicit awaiting-review next action and never claims live deployment.

## Integration and recovery
The worker coordinates with workforce registry, lifecycle, assignment, enterprise platform factory, requirements, architecture, frontend context, executive reporting, performance review, and recovery systems. Missing optional integrations must degrade gracefully without changing authority or boundary locks.
