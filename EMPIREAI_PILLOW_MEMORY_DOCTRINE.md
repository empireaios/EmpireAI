**EKLS authority:** Long-term institutional memory is owned by **EKLS** under Pillow governance — see `CANONICAL_EKLS_SPECIFICATION.md`. This doctrine governs **conversation vs knowledge lifetime** and Context Builder cost; it does not define a competing memory store.

---

## 1. Core doctrine

**Pillow shall remember knowledge, not conversations.**

| Layer | Lifetime |
|---|---|
| Conversation history | Temporary working context |
| Approved repository knowledge | Permanent operational memory |

---

## 2. Context construction

Before **every** OpenAI API request, Pillow shall:

1. Determine the **minimum knowledge** required for the current request.
2. Construct context **dynamically** — never replay full historical conversations.
3. Route approved outcomes into **canonical repository owners** after Grand King approval.
4. Treat the originating conversation as **disposable** after synchronization.

---

## 3. Examples

| Request type | Minimum context |
|---|---|
| Weather, general learning | No EmpireAI repository context |
| Update Journey | Journey + Latest Executive Audit + Active Backlog Release |
| Architecture discussion | Journey + Soul + Decision Register + Project Status |

---

## 4. Purpose

* Minimize OpenAI API cost  
* Reduce token consumption  
* Improve response speed  
* Ensure deterministic reasoning  
* Eliminate unnecessary historical context
